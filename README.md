# Akashvani Kannur Alexa Skill – Policy

This repository contains the **Privacy Policy** and **Terms of Use** for the
**Akashvani Kannur Alexa Skill**.

## About the Skill
The Akashvani Kannur Alexa Skill allows users to listen to live radio broadcasts
from **All India Radio (Akashvani Kannur)** using the official publicly available
broadcast stream.

## Data & Privacy
- This skill does **not** collect, store, or share any personal user data.
- All voice interactions are processed by Amazon Alexa in accordance with
  Amazon’s Privacy Policy.

## Purpose of This Repository
This repository exists solely to host a publicly accessible Privacy Policy and
Terms of Use page required for Alexa Skill certification.
